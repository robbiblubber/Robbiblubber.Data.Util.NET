## robbiblubber.org Data Utility CSV Library

The robbiblubber.org Data Utility CSV Library provides functionality for working with CSV files.

The repository can be found at https://github.com/robbiblubber/Robbiblubber.Data.Util.NET.
For general information see http://robbiblubber.org/.
