## robbiblubber.org Data Utility Excel Library

The robbiblubber.org Data Utility Excel Library provides functionality for working with Excel files.

The repository can be found at https://github.com/robbiblubber/Robbiblubber.Data.Util.NET.
For general information see http://robbiblubber.org/.
